    1. Sequence Limits

    Definition

    A sequence \(a_n\) approaches a limit \(L\) if the terms get infinitely close to \(L\) as \(n \to \infty\).

    Example

    Find: \(\lim_{n \to \infty} \frac{2n + 1}{n}\)

    Solution: $\(\frac{2n}{n} + \frac{1}{n} = 2 + \frac{1}{n} \implies 2 + 0 = 2\)$

    Practice

    Find limit of \(a_n = \frac{n+1}{n}\).

    Answer:

    Show Solution

    Divide by \(n\): $\(\lim_{n \to \infty} (1 + 1/n) = 1\)$

    2. Function Limits

    Definition

    Limits describe the behavior of a function near a point, even if the point itself is undefined (like \(0/0\)).

    Example

    Find: \(\lim_{x \to 3} \frac{x^2 - 9}{x - 3}\)

    Solution: Factorize: \(\frac{(x-3)(x+3)}{x-3} = x+3\). Result: \(3+3=6\).

    Practice

    Find limit of \(f(x) = \frac{x^2 - 1}{x - 1}\) as \(x \to 1\).

    Answer:

    Show Solution

    Factor: \((x-1)(x+1)\). Result: \(2\).

    3. Indeterminate Forms

    Definition

    The form \(0/0\) requires algebraic manipulation (factoring, conjugate, L'Hopital) to resolve.

    Example

    Find: \(\lim_{x \to 0} \frac{5x^2 + 10x}{x}\)

    Solution: Factor \(x\): \(\frac{x(5x+10)}{x} = 5x+10\). Result: \(10\).

    Practice

    Find limit of \(f(x) = \frac{2x^2 - 2}{x - 1}\) as \(x \to 1\).

    Answer:

    Show Solution

    Simplify: \(2(x+1) \to 4\).
