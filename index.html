    1. Sequence Limits

    📘 Theory: What is a Limit?

    A sequence \(a_n\) approaches a limit \(L\) if the terms get infinitely close to \(L\) as \(n \to \infty\). Think of it as the "destination" of the numbers.

    👁️‍🗨️ Solved Example

    Question: Find \(\lim_{n \to \infty} \frac{2n + 1}{n}\)

    Solution: Divide every term by \(n\): $\(\frac{2n}{n} + \frac{1}{n} = 2 + \frac{1}{n}\)$ As \(n \to \infty\), \(\frac{1}{n}\) becomes \(0\). Result: \(2 + 0 = 2\).

    🚀 Practice Task

    Find limit of \(a_n = \frac{n+1}{n}\).

    Answer:

    💡 Need a Hint?

    Try dividing both the numerator and denominator by $n$.

    Show Solution

    Divide by \(n\): $\(\lim_{n \to \infty} (1 + 1/n) = 1\)$

    2. Function Limits (The Hole)

    📘 Theory: Value vs. Limit

    Limits describe the behavior of a function near a point, not necessarily at the point. This allows us to handle "undefined" points like \(0/0\).

    👁️‍🗨️ Solved Example

    Question: Find \(\lim_{x \to 3} \frac{x^2 - 9}{x - 3}\).

    Solution: If we plug in \(3\), we get \(0/0\). Factor the numerator (Difference of Squares): $\(\frac{(x-3)(x+3)}{x-3} = x+3\)$ Now plug in \(3\): \(3+3=6\).

    🚀 Practice Task

    Find limit of \(f(x) = \frac{x^2 - 1}{x - 1}\) as \(x \to 1\).

    Answer:

    💡 Need a Hint?

    Use the difference of squares formula: $a^2 - b^2 = (a-b)(a+b)$.

    Show Solution

    Factor: \((x-1)(x+1)\). Result: \(2\).

    3. Indeterminate Forms

    📘 Theory: The 0/0 Mystery

    When you see \(0/0\), it is an Indeterminate Form. It means "do more work" (usually algebra) to find the hidden answer.

    👁️‍🗨️ Solved Example

    Question: Find \(\lim_{x \to 0} \frac{5x^2 + 10x}{x}\).

    Solution: Factor out \(x\) from the top: $\(\frac{x(5x + 10)}{x} = 5x + 10\)$ Now let \(x \to 0\): Result is \(10\).

    🚀 Practice Task

    Find limit of \(f(x) = \frac{2x^2 - 2}{x - 1}\) as \(x \to 1\).

    Answer:

    💡 Need a Hint?

    Factor out 2 first: $2(x^2 - 1)$.

    Show Solution

    Simplify: \(2(x+1) \to 4\).

    Final Test

    Task A (Multiple Choice)

    Limit of \(a_n = \frac{3n^2 + n}{n^2 - 5}\) as \(n \to \infty\).

    Select the correct answer:

    Solution

    Ratio of highest powers: \(3n^2 / n^2 = 3\).

    Task B

    Limit of \(f(x) = \frac{x^2 + 3x}{x}\) as \(x \to 0\).

    Solution

    Simplify: \(x+3 \to 3\).

    ⚡ Formulas

    ⚡ Cheat Sheet

    Difference of Squares:
    $a^2 - b^2 = (a-b)(a+b)$

    Limits at Infinity:
    $\frac{n^k}{n^k} \to 1$, $\frac{1}{n} \to 0$

    Common Limit:
    $\lim_{x \to 0} \frac{\sin x}{x} = 1$
